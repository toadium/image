## Patterns Applied
1. **Parallel-paragraph merge**: Chinese line + English line as separate `///` lines → single bilingual line
2. **Heading merge**: `/// # name` + `/// name` → `/// # 中文名 English name`
3. **Submodule text**: `/// Image processing library submodule` → `/// 图像处理库子模块 Image processing library submodule`
4. **16f variant descriptions**: `/// 16-bit/float X` → `/// 16位/浮点X 16-bit/float X`
5. **Function/type descriptions**: `/// Description` → `/// 中文描述 Description`
6. **Formula lines**: Added Chinese label prefix (e.g., `/// 旋度 curl = ...`, `/// 拉普拉斯 lap = ...`)
